## 一、4 个阻塞项的答复



| 编号   | 事项         | 甲方答复                                                                                   |
| ---- | ---------- | -------------------------------------------------------------------------------------- |
| L001 | 待确认订单占不占库存 | **选 A：提交订单即锁定库存**，酒店须在 T 分钟内确认，超时自动取消并释放库存。理由：顾客下单即有保障，「先到先得」可落地；防恶意占房靠超时释放；与主流预订体验一致。 |
| L002 | 占住时长 T     | **T = 30 分钟**。超时释放由**系统定时任务**触发（周期性扫描超时的待确认订单），不做惰性判定；一期不做超时前提醒。                       |
| L004 | 一笔订单能否订多间房 | **允许**（真实场景「一家订两间」很常见）。重复预订规则相应修改为：**同一顾客、同一酒店、同时段、同一房型不得有两条有效订单**；不同房型允许（对应 L018）。    |
| L005 | 支付进不进一期    | **选 A：一期完全不做支付，到店前台结算**。不做支付时，取消与 no-show 只记状态、不做违约金、不限制再订（对应 L006 接受）。                |
