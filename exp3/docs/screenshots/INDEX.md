# 界面截图索引（S6-2）

十屏截图全部来自本机实际运行的桌面程序（Python 3.12 + Tkinter + SQLite，无设计器、无生成代码）。
每张图的操作步骤都是可复现的三步，数据来自 `code/tools/take_screenshots.py` 的临时库
（`init_db --seed` 的种子数据 + 6 笔演示订单，覆盖六种状态）。

## 复现方式

```
cd exp3
.\.venv\Scripts\python.exe code\tools\ui_smoke.py         # 十屏逐个构造 → destroy，打印屏名与 check=passed
.\.venv\Scripts\python.exe code\tools\take_screenshots.py # 重新生成这 10 张 PNG（临时库，不落生产库）
```

> 截图口径：窗口按 DPI 折算成约 1639×959 物理像素后抓屏；表格列宽统一按「比例分配」
> （`stretch=True`），避免某一列吃满宽度把后面的列顶出可视区。
